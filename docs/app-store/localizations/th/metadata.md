## Description

Beacon Survival SOS คือผู้ช่วยฉุกเฉินแบบออฟไลน์สำหรับช่วงเวลาที่ไม่มีเครือข่ายและทุกวินาทีมีความสำคัญ

Beacon ใช้ Gemma บน iPhone และค้นหาความรู้ด้านความปลอดภัยสาธารณะที่ฝังไว้ก่อนตอบ ช่วยจัดลำดับขั้นตอนในสถานการณ์หลงป่า ภัยพิบัติ บาดเจ็บ ไฟไหม้ เลือดออก การหลบภัยจากรังสี ไฟดับ และวิกฤตอื่น ๆ

คุณสมบัติหลัก:
- คำแนะนำฉุกเฉิน Gemma บนอุปกรณ์
- ค้นหาความรู้ความปลอดภัยสาธารณะแบบออฟไลน์
- ความช่วยเหลือจากกล้องหรือรูปภาพ
- อ้างอิงแหล่งข้อมูลทางการแพทย์และความปลอดภัย
- หน้าจอเรียบง่ายพร้อมปุ่มฉุกเฉินขนาดใหญ่
- 20 ภาษา UI รวม RTL
- ไม่ต้องมีบัญชี ไม่ใช้คลาวด์ ไม่มีโฆษณา ไม่ติดตาม

Beacon ไม่ใช่สิ่งทดแทนบริการฉุกเฉิน การรักษาพยาบาล เจ้าหน้าที่กู้ภัย หรือคำแนะนำทางการ เมื่อมีสัญญาณ ให้ติดต่อบริการฉุกเฉินหรือผู้เชี่ยวชาญในพื้นที่
