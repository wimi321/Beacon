## Description

Beacon Survival SOS — офлайн-помічник для надзвичайних ситуацій, коли немає мережі й важлива кожна секунда.

Beacon запускає Gemma на iPhone і перед відповіддю звертається до вбудованих матеріалів громадської безпеки. Він допомагає продумати дії під час виживання на природі, катастроф, травм, опіків, кровотечі, радіаційного укриття, відключення електрики та інших криз.

Основні можливості:
- Екстрені підказки Gemma на пристрої
- Офлайн-пошук у джерелах громадської безпеки
- Візуальна допомога з камери або фото
- Посилання на медичні та безпекові джерела
- Простий інтерфейс із великими екстреними кнопками
- 20 мов UI, зокрема RTL
- Без акаунта, без хмарного виводу, без реклами, без відстеження

Beacon не замінює екстрені служби, медичну допомогу, рятувальників або офіційні інструкції. Якщо зв'язок доступний, зверніться до місцевих служб або кваліфікованих фахівців.
