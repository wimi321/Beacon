## Description

Beacon Survival SOS는 네트워크가 끊기고 시간이 중요한 순간을 위한 오프라인 긴급 도우미입니다.

Beacon은 iPhone에서 Gemma를 실행하고, 답변 전에 내장된 공공 안전 지식을 검색합니다. 숲이나 산에서 길을 잃었을 때, 재난, 부상, 화상, 출혈, 방사선 대피, 정전, 통신 장애 같은 상황에서 다음 행동을 정리하도록 돕습니다.

주요 기능:
- 기기 내 Gemma 긴급 안내
- 오프라인 공공 안전 지식 검색
- 카메라 또는 사진 기반 시각 도움
- 의료 및 공공 안전 정보의 출처 표시
- 쉽게 누를 수 있는 큰 긴급 버튼
- 20개 UI 언어 및 RTL 지원
- 계정 없음, 클라우드 추론 없음, 광고 없음, 추적 없음

Beacon은 응급 서비스, 전문 의료, 구조대 또는 공식 안전 지침을 대체하지 않습니다. 통신이 가능하면 지역 응급 서비스나 전문가에게 연락하세요.
