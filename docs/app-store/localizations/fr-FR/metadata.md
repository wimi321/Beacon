## Description

Beacon Survival SOS est un assistant d'urgence hors ligne conçu pour les moments où le réseau tombe et où chaque seconde compte.

Beacon exécute Gemma sur votre iPhone et consulte des connaissances publiques intégrées avant de répondre. Il peut aider à organiser les prochaines actions en survie extérieure, catastrophe, blessure, brûlure, saignement, abri contre les radiations, panne de courant ou autre crise.

Fonctions clés :
- Guidage Gemma sur l'appareil
- Recherche hors ligne de connaissances de sécurité publique
- Aide visuelle avec caméra ou photos
- Citations de sources médicales et de sécurité publique
- Interface simple avec grands boutons d'urgence
- 20 langues d'interface, y compris RTL
- Aucun compte, aucune inférence cloud, aucune publicité, aucun suivi

Beacon ne remplace pas les services d'urgence, les soins médicaux, les secours professionnels ni les consignes officielles. Si la communication est disponible, contactez les secours locaux ou un professionnel qualifié.
