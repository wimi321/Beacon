## Description

Beacon Survival SOS 是为断网、低电量和极端压力场景准备的离线应急助手。

Beacon 在 iPhone 本机运行 Gemma，并在回答前检索内置公共安全资料。它可以帮助你梳理野外求生、灾害避险、创伤、烧伤、出血、辐射避险、停电断网等危机场景中的下一步行动。

核心能力：
- 端侧 Gemma 应急指引
- 离线公共安全知识库检索
- 拍照或相册图片视觉求助
- 医疗和公共安全建议显示来源引用
- 傻瓜化的大按钮求助界面
- 支持 20 种界面语言和 RTL 排版
- 无账号、无云端推理、无广告、无追踪

Beacon 不能替代急救电话、专业医疗、救援人员或官方公共安全指令。一旦恢复通信，请尽快联系当地急救、救援或专业人员。
