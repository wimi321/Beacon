## Description

Beacon Survival SOS は、通信が不安定な時や一刻を争う場面のためのオフライン緊急アシスタントです。

Beacon は iPhone 上で Gemma を実行し、回答前に内蔵の公共安全知識を参照します。山や森での迷子、災害、けが、やけど、出血、放射線退避、停電、通信障害などで次に何を確認し、どう動くべきかを整理します。

主な機能：
- 端末上の Gemma による緊急ガイダンス
- オフライン公共安全知識の検索
- カメラまたは写真による視覚ヘルプ
- 医療・公共安全情報の出典表示
- 迷わず押せる大きな緊急ボタン
- 20 種類の UI 言語と RTL 対応
- アカウント不要、クラウド推論なし、広告なし、追跡なし

Beacon は救急サービス、医療従事者、救助隊、公式の安全指示の代替ではありません。通信が使える場合は、地域の緊急窓口や専門家に連絡してください。
