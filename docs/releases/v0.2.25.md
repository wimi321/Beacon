# Beacon v0.2.25

## Highlights
- Fixes App Store Connect Swift runtime packaging by embedding the required Swift standard libraries in both `Payload/App.app/Frameworks` and `SwiftSupport/iphoneos`.
- Preserves the v0.2.24 application experience while correcting the iOS distribution package structure required by Apple validation.
- Keeps the Android release artifact aligned with the same source revision.

## Validation
- SwiftSupport packaging verification: 17 Swift dylibs in `Payload/App.app/Frameworks` and 17 matching dylibs in `SwiftSupport/iphoneos`.
- App bundle code signature verification passed after Swift runtime embedding.
- Web tests, production web build, Android release build, iOS archive, and App Store export/upload are expected release gates for this version.
