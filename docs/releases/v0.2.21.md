# Beacon v0.2.21

Release date: 2026-05-30

## Highlights

- iOS App Store follow-up build: `0.2.21 (33)`
- Safer LiteRT-LM runtime bridge with clearer native diagnostics
- Vision-artifact validation on iOS, so photo analysis is only offered when the bundled Gemma 4 vision package is actually valid for the runtime
- Output cleanup for repeated or degenerate model tails before display
- Real-device UI smoke coverage for home, chat, language switching, visual picker entry, and back navigation
- Android metadata bumped to `versionCode 24` / `versionName 0.2.21`

## Verification

- `npm test -- --run` — 127 tests passing
- `npm run build`

## Notes

Beacon remains offline-first and does not use cloud inference, advertising, accounts, or tracking.
