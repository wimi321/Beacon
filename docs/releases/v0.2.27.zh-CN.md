# Beacon v0.2.27

## 重点更新
- 修复 App Store Connect `ITMS-90208`：生成的 `GemmaModelConstraintProvider.framework` 会和 LiteRT runtime 二进制真实写入的最低系统版本保持一致。
- iOS App 最低系统版本提升到 `iOS 26.2`，与当前内置的官方 Gemma constraint-provider runtime 匹配，避免 App Store 处理阶段拒绝。
- 保留 v0.2.26 的 framework 打包修复：`Payload/App.app/Frameworks` 顶层不再存在非 Swift 的裸 dylib。
- Android 安装包同步使用同一份源码版本。

## 验证项
- `vtool -show-build` 确认 `GemmaModelConstraintProvider` 真实要求 `iOS 26.2`。
- IPA 检查需确认 App 版本为 `0.2.27 (39)`、App 最低系统版本 `26.2`、framework 最低系统版本 `26.2`、顶层非 Swift 裸 dylib 数量为 0、SwiftSupport 结构有效。
- 发布门槛包括 Web 单测、生产构建、Android release 构建、iOS archive、App Store 导出与上传。
