# Beacon v0.2.26

## Highlights
- Fixes App Store Connect `ITMS-90429` by packaging Beacon's Gemma model constraint provider as `GemmaModelConstraintProvider.framework` instead of a loose top-level dylib.
- Rewrites the `CLiteRTLM.framework` runtime dependency at build time so it links to the framework-packaged constraint provider.
- Keeps third-party non-system dynamic libraries inside framework bundles while retaining Apple's Swift standard libraries in the required SwiftSupport layout.
- Keeps the v0.2.25 application behavior unchanged while correcting the iOS distribution package structure required by Apple validation.

## Validation
- IPA inspection confirms no non-Swift loose dylibs remain in `Payload/App.app/Frameworks`.
- `CLiteRTLM.framework` links to `@rpath/GemmaModelConstraintProvider.framework/GemmaModelConstraintProvider`.
- SwiftSupport packaging verification remains enabled for Apple Swift runtime libraries.
- Web tests, production web build, Android release build, iOS archive, App Store export, and upload are release gates for this version.
