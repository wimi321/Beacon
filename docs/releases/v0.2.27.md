# Beacon v0.2.27

## Highlights
- Fixes App Store Connect `ITMS-90208` by aligning the generated `GemmaModelConstraintProvider.framework` `MinimumOSVersion` with the real minimum OS encoded in the LiteRT runtime binary.
- Raises the iOS app deployment target to `iOS 26.2`, matching the official Gemma constraint-provider runtime that Beacon bundles for on-device Gemma 4 E2B.
- Keeps the v0.2.26 framework packaging fix intact: no non-Swift loose dylibs remain at the top level of `Payload/App.app/Frameworks`.
- Keeps Android aligned with the same source revision.

## Validation
- `vtool -show-build` confirms `GemmaModelConstraintProvider` requires `iOS 26.2`.
- IPA inspection must confirm app version `0.2.27 (39)`, app minimum OS `26.2`, framework minimum OS `26.2`, 0 non-Swift loose dylibs, and valid SwiftSupport layout.
- Release gates include Web tests, production web build, Android release build, iOS archive, App Store export, and App Store upload.
