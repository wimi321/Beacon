# Beacon v0.2.25

## 重点更新
- 修复 App Store Connect 的 Swift runtime 打包校验问题：Swift 标准库现在会同时放入 `Payload/App.app/Frameworks` 和 `SwiftSupport/iphoneos` 两个苹果要求的位置。
- 保持 v0.2.24 的应用体验不变，只修正 iOS 分发包结构，解决上传后处理失败的问题。
- Android 安装包同步使用同一份源码版本发布。

## 验证项
- SwiftSupport 打包验证：`Payload/App.app/Frameworks` 中 17 个 Swift dylib，`SwiftSupport/iphoneos` 中 17 个匹配 dylib。
- App bundle 重新签名后通过 `codesign --verify`。
- 本版本发布门槛包括 Web 单测、生产构建、Android release 构建、iOS archive、App Store 导出与上传。
