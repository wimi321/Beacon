# Beacon v0.2.23 - App Store SwiftSupport 签名修复

发布日期：2026-05-30

## 重点

- iOS App Store 跟进版本：`0.2.23 (35)`。
- 修复 Apple 处理错误 `ITMS-90433`：`SwiftSupport/iphoneos` 改为从 Xcode 原始 Swift 运行库生成，不再复制 App 包内已经重签名的 dylib。
- 保留 v0.2.21/v0.2.22 的 runtime 加固：LiteRT 桥接安全检查、视觉模型包验证、生成内容显示清理，以及 App Store 审核资料。
- Android GitHub APK 继续保持用户自行下载模型，仍然是真实本地 Gemma 推理链路。

## 验证

- `npm test -- --run`
- `npm run build`
- `npm run mobile:build`
- Android release APK 构建
- iOS App Store archive/export/upload，并验证 SwiftSupport 使用 Apple 原始签名
