# Beacon v0.2.23 - App Store SwiftSupport Signature Fix

Release date: 2026-05-30

## Highlights

- iOS App Store follow-up build: `0.2.23 (35)`.
- Fixes Apple processing error `ITMS-90433` by generating `SwiftSupport/iphoneos` from Xcode's original Swift runtime libraries instead of re-signed app-bundle copies.
- Keeps the full v0.2.21/v0.2.22 runtime hardening: safer LiteRT bridge checks, visual-artifact validation, cleaner generated-response display, and App Store review metadata.
- Android GitHub APK remains user-download-model first and keeps the real local Gemma pipeline.
