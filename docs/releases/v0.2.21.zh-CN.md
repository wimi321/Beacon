# Beacon v0.2.21

发布日期：2026-05-30

## 重点更新

- iOS App Store 跟进版本：`0.2.21 (33)`
- 加强 LiteRT-LM 原生安全桥接和运行时诊断
- 增加 iOS 视觉模型包校验：只有模型包真正符合当前 Gemma 4 视觉运行合约时，才开放照片分析，避免假装看图
- 优化模型输出清理，截断明显重复或退化的尾巴，避免最终显示污染
- 增加真机 UI 烟测覆盖：首页、快捷求助、进入对话、语言切换、视觉入口、左侧返回手势
- Android 元数据升级到 `versionCode 24` / `versionName 0.2.21`

## 验证

- `npm test -- --run`：127 条测试通过
- `npm run build`

## 说明

Beacon 继续保持离线优先，不使用云端推理、广告、账号或追踪。
