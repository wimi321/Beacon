# Beacon v0.2.24 - App Store Swift Runtime Packaging Fix

Beacon v0.2.24 is a release-candidate packaging fix for App Store Connect processing.

## What's New

- Removes manual Swift standard-library staging from the iOS LiteRT asset build phase.
- Lets Xcode's official `CopySwiftLibs` pipeline decide whether Swift runtime files are required for the iOS 15+ app bundle.
- Avoids mismatched `SwiftSupport` and `Payload/App.app/Frameworks/libswift*.dylib` entries that caused App Store Connect `ITMS-90429` on build 35.
- Keeps the recent review-readiness fixes intact: iPhone-only distribution, local Gemma 4 E2B bundle, medical source citations, privacy purpose strings, portrait-only UI, and simplified emergency flow.

- Android: `versionCode 27`, `versionName 0.2.24`
