# Beacon v0.2.24 - App Store Swift 运行库打包修复

Beacon v0.2.24 是一次面向 App Store Connect 处理流程的发布候选修复。

## 更新内容

- 移除 iOS LiteRT 资源构建阶段中手工复制 Swift 标准库的逻辑。
- 改为完全交给 Xcode 官方 `CopySwiftLibs` 流程判断 iOS 15+ App 包是否需要 Swift runtime 文件。
- 避免 `SwiftSupport` 与 `Payload/App.app/Frameworks/libswift*.dylib` 不匹配，从而修复 build 35 遇到的 App Store Connect `ITMS-90429`。
- 保留最近已通过审核方向的修复：iPhone-only 分发、本地内置 Gemma 4 E2B、医学资料引用、隐私用途说明、竖屏锁定和简化急救流程。

## 版本

- iOS：`0.2.24 (36)`
- Android：`versionCode 27`，`versionName 0.2.24`

## 验证

- 使用 Xcode 当前公开 GM 工具链完成 iOS archive。
- 本地 App Store 导出成功。
- IPA 结构审计确认导出包不再包含冲突的 SwiftSupport / Swift runtime 嵌入项。
- App Store Connect 上传成功，build `0.2.24 (36)` 已进入 Apple 处理队列。
- Web 与 Android release 检查会随仓库发布流程一并验证。
