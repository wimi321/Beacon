# Beacon v0.2.26

## 重点更新
- 修复 App Store Connect `ITMS-90429`：Beacon 的 Gemma model constraint provider 不再作为顶层裸 dylib 放入 App，而是封装为合法的 `GemmaModelConstraintProvider.framework`。
- 构建时会把 `CLiteRTLM.framework` 对 constraint provider 的依赖改写到 framework 路径，避免苹果把第三方 dylib 误判为非法 SwiftSupport 包结构。
- 第三方非系统动态库全部保持在 framework bundle 内；苹果 Swift 标准库继续保留 `SwiftSupport` 所需结构。
- 应用体验保持 v0.2.25 不变，本版本专注修正 iOS 分发包结构。 

## 验证项
- IPA 检查确认 `Payload/App.app/Frameworks` 中不再存在非 Swift 的顶层裸 dylib。
- `CLiteRTLM.framework` 已链接到 `@rpath/GemmaModelConstraintProvider.framework/GemmaModelConstraintProvider`。
- SwiftSupport 脚本继续为苹果 Swift runtime 保留必要校验。
- 本版本发布门槛包括 Web 单测、生产构建、Android release 构建、iOS archive、App Store 导出与上传。
